# සුවධරා Ayurveda Sample Website

NextWave Marketing විසින් Ayurvedic products business එකක් සඳහා නිර්මාණය කළ responsive Sinhala sample website එකකි.

## GitHub Pages එකට Publish කිරීම

1. GitHub හි අලුත් repository එකක් සාදන්න.
2. මෙම folder එක ඇතුළත ඇති `index.html`, `style.css`, `script.js` සහ `assets` folder එක repository එකට upload කරන්න.
3. Repository → **Settings** → **Pages** වෙත යන්න.
4. **Deploy from a branch** තෝරන්න.
5. Branch එක `main` සහ folder එක `/root` තෝරා **Save** කරන්න.
6. මිනිත්තු කිහිපයකින් website link එක ලැබේ.
